# 美股市场工作台 | US Market Workbench

与A股股票池完全独立的 **标普500 / 纳斯达克** 在线分析网页。

## 启用网页（仅需一次）
1. 进入仓库 Settings → Pages。
2. 在 Build and deployment → Source 选择 Deploy from a branch。
3. Branch 选择 main，Folder 选择 /(root)，点击 Save。
4. 等待 GitHub Pages 发布，网页地址： https://huashihao94-ux.github.io/us-market-workbench/

## 第一次获取指数行情
1. 打开仓库 Actions → Update index data → Run workflow → Run workflow。
2. 检查工作流显示绿色完成。
3. 页面点击“刷新数据”，读取最新发布的 data.json。

仓库中 .github/workflows/update.yml 将在美国交易时段附近定时重新获取数据，脚本在 scripts/update_data.py。
网页刷新只重新下载最新缓存文件，不会直接运行 Python 或实时向交易所询价。

## 功能
- 标普500（^GSPC）、纳斯达克综合指数（^IXIC）的最新可获取日收盘价。
- 最近252个交易日最高收盘价回撤%、200日均线偏离%、高点后交易日数。
- 两张历史曲线图：一年高点回撤、200日均线偏离。
- 选择2010、2012、2015、2018、2020、2025、2026历史事件，横轴对齐高点后的交易日。
- 资料表来自用户提供的视频截图，图表曲线由市场数据重新计算，两个口径可能存在差异。
- 数据源：标普500优先读取 Cboe SPX_History.csv；纳斯达克综合指数优先读取 Nasdaq 公开历史行情接口；若失败再尝试美联储 FRED、Yahoo Finance 和 Stooq。GitHub Actions 已于2026-11-23成功获取两项指数截至2026-11-20的收盘数据，后续可用性不保证。网页会标明来源、日线日期及缓存状态；不编造行情。公开分发行情数据可能涉及指数提供方的授权与再发布限制，面向公众或商业使用前应核实许可。

## 计算方法和限制
一年高点使用最近252个交易日**最高收盘价**，不是盘中最高价。200日均线取200个交易日收盘价简单平均。历史路径起点取事件底部前252个交易日最高收盘价。

GitHub Actions 的计划任务可能延迟、限流、无法访问数据源。GitHub Pages 静态页面**不具备逐笔实时行情**，它显示最新成功生成的数据文件。请勿直接根据历史底部中位数进行买卖决策。

公开仓库不要存储API密钥或个人隐私数据。

## 独立模块：烟蒂股估值（Michael Burry 风格）

点击工作台顶部的 **「烟蒂股估值」**，或访问 [burry.html](https://huashihao94-ux.github.io/us-market-workbench/burry.html)。

- 输入股票名称、股价、股数、财务指标，自行核对公司财报与数据日期。
- 按用户的烟蒂股笔记显示 PE＜15倍（优选＜10倍）、PB＜1倍、股息率≥3% 的初筛检查；三项不要求同时满足。
- 计算市值、EV、EV/EBITDA、FCF收益率、NCAV以及自设的EV/EBITDA倍数与FCF倍数估值。
- 根据用户设置的安全边际计算参考买入价；显示52周低点上方10%—15%的观察区间和现金流/财务风险提醒。
- 支持浏览器本地保存、导出JSON备份；**尚不支持跨设备云端同步、自动输入实时财务数据或真实股票库模糊检索**。没有输入就显示“—”，不会伪造数据。
- 页面内“示例公司”为虚构数据，仅用于演示公式。默认5倍EV/EBITDA、10倍FCF与30%安全边际是可编辑假设，**不是Michael Burry公布的统一估值规则**。

本模块仅是价值投资研究工具，不提供交易建议，不会修改现有指数分析功能。A股股票池是独立项目，未在此仓库内修改。

## 分类股票池（四个估值观察区）

打开 [分类股票池](https://huashihao94-ux.github.io/us-market-workbench/workbench.html)，或在指数分析首页点击顶部 **② 分类股票池**。

### 工作流程

1. **股票名称优先模糊搜索**，匹配公司名（附部分中文别名）；若名称无结果，再按美股代码搜索。点选候选股票代码。
2. 选择归属类别：**护城河白马股 / 巨无霸公司 / 优秀成长股 / 烟蒂股**。同一股票只归入一个主观察区，分类可修改。
3. 在分类卡片点击已加入的股票，录入最新股价、财报数据与日期；页面自动计算估值、显示条件检查、横向距离条及 **达标 / 未达标 / 待补数据**。
4. 数据会在当前浏览器本地保存。支持导出/导入 JSON 备份；当前**没有跨设备账户同步**，也**没有自动拉取个股实时财务报表或股价**。
5. 烟蒂股类别可一键打开 [Michael Burry 估值工具](https://huashihao94-ux.github.io/us-market-workbench/burry.html)，股票名称和代码可带入独立页面。

### 规则出处与提示

- **白马股**：你的笔记倾向20倍PE（特别优秀的可接受25倍），并参考ROE和护城河状况；默认以PE≤20、ROE≥20%、人工确认护城河为达标。20% ROE是笔记里的参考，不是巴菲特个人规定的绝对统一阈值。
- **巨无霸**：按笔记示例，假设10年净利润年增长5%，计算PE＝2×5＋10＝20倍；默认上限为20倍，沿用护城河人工检查。大公司也可能是白马股，此处只是单独观察类目。
- **优秀成长股**：盈利时参考“PE＝2×预计利润增速＋10”，笔记示例g＝30则PE＝70。无盈利时切换PS＋未来3—5年PE模型，笔记示例100亿美元市值/20亿收入/50%收入增长/20%净利率，三年后的预测PE约7.4。20%最低增长率、20倍未来PE等是用户可编辑的演示阈值。
- **烟蒂股**：用户笔记优先观察PE<15（更偏好<10）、PB<1、股息≥3%，低估值信号只需至少一项触发；还用可编辑的30%安全边际与52周低点上浮15%区间确定执行层面的「达标」。Burry没有固定统一倍数模型；这些门槛是本工具的自定义规则，非他本人保证有效的标准。
- **银行**：在白马或巨无霸个股中启用“银行股”复选框，改用PB与自填历史参考PB比较，而不是机械套用通常的PE规则。

### 股票名称目录

初始 `symbols.json` 含少量常用美股；`.github/workflows/update_symbols.yml` 会按周尝试从美国SEC官方 [company_tickers_exchange.json](https://www.sec.gov/files/company_tickers_exchange.json) 更新完整公司名称和代码索引。请检查 GitHub Actions 的 **Update stock name directory** 是否成功，因源站限流、GitHub权限或运行环境问题不能保证持续更新。

**重要限制**：本工具不提供实时交易信号，也不保证输入数据准确；“达标”仅代表当前填写的数据满足这个类别的用户配置的模型条件，不代表值得买入或股价马上到达目标区。金额输入的单位是亿美元，价格输入单位为美元/股。

## 自动名称搜索和估值数据（2026-11-23 升级）

**分类股票池第二个分页已加载 `auto_data.js`。** 股票名称与代码使用 `symbols.json`；优先通过定时任务更新SEC官方的公司名称、交易所、股票代码及CIK；如果首次只有少量内置股票，网页会尝试读取 [交易所代码镜像](https://github.com/e1001925/Improved-US-Stock-Symbols) 作为名称搜索备用，不应把镜像等同于SEC权威名单。

### 自动行情和财报来源

- `fundamentals.json` 由 `scripts/update_fundamentals.py` 和 GitHub Actions 的 `Refresh US stock prices and SEC annual metrics` 生成。**美股交易日后**尝试获取最近可得的日线收盘价（Yahoo Finance未正式公开授权的chart接口；Stooq CSV备用），**每周**尝试更新 SEC EDGAR XBRL 财务数据。接口可能限流、阻止Github云服务器或不支持某些海外发行人。缓存缺失会显示“暂无数据”，不会臆造股价或财务数字。
- 当前后台跟踪清单在 `tracked_symbols.json`，初始为 **71只常用股票**。只要编辑该JSON数组增加合法代码并提交，下次工作流就会尝试纳入自动行情/财报。**完整搜索目录不代表所有股票都已自动拉取财报或股价**。
- 每一条自动数据附来源和数据期。SEC提取的EPS、营业收入、净利润、现金流大多是**最近完整财年**而非TTM；净资产、现金、负债是最近披露的时点数据；股数可能使用已报告流通股数或年度加权股数；FCF和EBITDA可能是依据现金流/利润表计算的近似值。
- 财务的预测参数（未来3—10年利润增速、未来营业收入增长率、未来利润率、合理估值倍数、行业PB标准等）不会从历史数据自动填充。
- 手工编辑过的数据优先保留：自动更新仅填空或刷新之前由自动源填的项目。需要替换手填数字时在股票分析页点击“覆盖手填财务数据”并确认。
- 免费数据源不是交易所实时授权行情，存在行情延迟、历史调整、失效和公开再发布授权限制；请只将本工作台用于个人研究，公开商业使用前核实市场数据授权条款。

### 检查是否已成功获取真实数据

1. 仓库 [Actions](https://github.com/huashihao94-ux/us-market-workbench/actions) 中选择 **Refresh US stock prices and SEC annual metrics** 查看日志。
2. 如果首次缓存仍为 `mode: pending` 或 `stocks: {}`，说明**更新任务尚未成功发布**；可使用工作流里的 **Run workflow / full**（仓库须允许 Actions 写入）。
3. 更新成功后，`fundamentals.json` 将有真实股票记录，第二个分页顶部会显示有股价和有财报的数量、刷新时间；股票分析区也将显示数据日期与源。
4. 对于SEC请求，建议在仓库 Secrets 中设置 `SEC_USER_AGENT`，格式为“应用名称 联系邮箱”，并保持合理请求频率。不要把任何API密钥写进公开网页或GitHub代码。

**跨设备云端双向同步尚未实现**，观察区目前保存在浏览器本地，支持手动JSON导入导出；云端账号同步需要另配受保护的数据库和身份验证。

巨无霸是一个**自动的、市值量化类目**：最新可用股价（美元）×披露股数（亿股）＞5000 亿美元（即超过5000亿美元）时，自动归类为巨无霸。在股票搜索后显示市值；如果股数/股价不可得，则显示**市值待核实**，不会假定符合条件。估值为`TTM PE = 当前价 / 最近12个月稀释EPS`；**20倍以内为优选，20–25倍为弹性参考区，超过25倍未达标**，长期亏损或无法计算则为“待补数据”。任何可接受区间仅是用户个人笔记参数，不是投资结论。总股数可能来自SEC披露的时点股数/年度加权股数，不同股权类别的巨型企业需额外核对总股本。

自动财报脚本将年度EPS与TTM EPS分开输出：`eps`为最近年报EPS；`ttmEPS`优先为最近完整年报的12个月EPS，若有更新的季报则用【上一完整财年EPS＋当前年度累计EPS－去年同期累计EPS】推导，显示报告期。跨期股本增发、股票拆分、ADR、海外公司、银行与多股权类别可能使这个近似不准确。缺失时不会自动拿年度EPS假冒已经更新到最近季度的TTM EPS。
